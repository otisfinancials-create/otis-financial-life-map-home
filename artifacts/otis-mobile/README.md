# Otis Mobile (Expo) — DEPRECATED / PAUSED

**Do not build new features here.**

As of 2026-07-31 the product is **PWA-only**: the mobile experience is the
web app (`artifacts/otis`), which is installable on iOS and Android as a
Progressive Web App. This native Expo/React Native app is retired and will
never ship to the Apple/Google app stores.

- The code is kept for reference only; it is not maintained.
- Nothing in the web app or API server depends on this package — it only
  *consumes* the shared API server and generated client types.
- Mobile feature work belongs in `artifacts/otis` (the PWA).
